# FitStore Mini Katalog Uygulaması

Bu proje, Flutter günlük eğitimi kapsamında geliştirilmiş spor temalı bir mini katalog uygulamasıdır. Uygulama içerisinde spor ürünleri listelenmekte, ürün detay sayfası görüntülenebilmekte ve sepete ekleme işlemi gerçekleştirilebilmektedir.

## Proje Özellikleri

- Ana sayfa ve ürün listeleme
- GridView ile ürün kartları
- Ürün detay sayfası
- Navigator ile sayfa geçişleri
- Sayfalar arası veri taşıma
- Sepete ekleme işlemi
- Basit state yönetimi
- Responsive kullanıcı arayüzü

## Kullanılan Teknolojiler

- Flutter
- Dart
- Material Design
- Visual Studio Code

## Flutter Sürümü

Flutter 3.41.9  
Dart 3.11.5

## Proje Yapısı

Proje kodları `lib/main.dart` dosyasında bulunmaktadır.

## Çalıştırma Adımları

Projeyi çalıştırmak için terminalde aşağıdaki komutlar kullanılmalıdır:

```bash
flutter pub get
flutter run
```
