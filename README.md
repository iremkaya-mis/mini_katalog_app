# Mini Katalog Uygulaması

Bu proje, Flutter günlük eğitimi kapsamında geliştirilmiş spor temalı bir mini katalog uygulamasıdır.

## Proje Amacı

Uygulamanın amacı Flutter kullanarak temel mobil uygulama geliştirme mantığını öğrenmektir. Projede widget yapısı, sayfa geçişleri, veri modeli, GridView kullanımı ve basit state yönetimi uygulanmıştır.

## Kullanılan Teknolojiler

- Flutter
- Dart
- Material Design
- Visual Studio Code

## Uygulama Özellikleri

- Ana sayfa
- Spor ürünleri listeleme
- GridView ile ürün kartları
- Ürün detay sayfası
- Navigator ile sayfa geçişi
- Sayfalar arası veri taşıma
- Sepete ekle butonu
- Basit state güncelleme

## Proje Yapısı

Ana uygulama kodları `lib/main.dart` dosyasında yer almaktadır.

## Çalıştırma Adımları

Projeyi çalıştırmak için terminalde aşağıdaki komutlar kullanılabilir:

```bash
flutter pub get
flutter run
```
